## Creating New Tracks

Run `/conductor:new-track` to create a new track with:
- Specification document
- Phased implementation plan
- Progress tracking

## Track Types

| Type | Description | Example |
|------|-------------|---------|

| `refactor` | Code improvement | API client restructure |
| `chore` | Maintenance | Dependency updates |
